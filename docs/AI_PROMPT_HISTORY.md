\# AI Prompt History — PayrollGuard AI



\## AI Tool Used

ChatGPT (OpenAI)



\## How AI Was Used



ChatGPT was used as a development assistant throughout the project. I used it to understand technical concepts, discuss implementation approaches, troubleshoot errors and review parts of the application.



I remained responsible for setting up the project, executing the implementation steps, configuring the development environment, running the application, checking database records and verifying the results.

\### 1. Understanding the Project

\- Explain the payroll validation requirements in simple terms.

\- Help me understand the expected workflow and project deliverables.

\- Explain how payroll processing, validation and reconciliation work.



\### 2. Database and Data Generation

\- Explain how to create the required MySQL tables and relationships.

\- Help me troubleshoot database setup and SQL errors.

\- Explain how to generate reproducible synthetic payroll records.

\- Help me investigate duplicate records and unexpected data statuses.



\### 3. Backend Implementation

\- Explain how to structure the FastAPI application.

\- Help me understand payroll calculation and validation logic.

\- Help me troubleshoot API errors and database integration issues.

\- Explain how approval, exception resolution and audit logging should work.



\### 4. Frontend Implementation

\- Explain how to connect a React frontend to FastAPI endpoints.

\- Help me troubleshoot frontend implementation and API integration.

\- Explain how to display payroll, employee, approval and exception information.



\### 5. Testing and Debugging

\- Help me understand unexpected results from SQL queries.

\- Explain why payroll exports are blocked when validation issues remain unresolved.

\- Help me verify payroll calculations and reconciliation.

\- Explain errors encountered while running the application.



\### 6. Documentation and GitHub

\- Help me understand the required documentation.

\- Explain Git staging, commits and pushing changes to GitHub.

\- Help me review the repository before submission.
